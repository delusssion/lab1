# Лабораторная работа 1 — Калькулятор (рекурсивный спуск - M1)

Простой калькулятор выражений с разбором рекурсивным спуском, валидацией токенов и набором модульных тестов.

## Цель проекта
Реализовать парсер-вычислитель арифметических выражений (рекурсивный спуск) с корректной обработкой приоритетов операций, скобок, унарных операторов и проверкой распространённых ошибок ввода.

## Алгоритм работы калькулятор
1. Tokenizer:
   - Очищает пробелы, разбивает входную строку на токены (числа, операторы, скобки).
   - Выполняет базовую валидацию: проверяет пропущенные операторы между числами и скобками.
   - Проверяет корректность формата чисел (ведущие нули, множественные точки).
2. Parser (рекурсивный спуск):
   - parse_expression → parse_addition → parse_multiplication → parse_power → parse_unary → parse_primary
   - Обрабатывает приоритеты: ** (правоассоциативно) → *, /, //, % → +, -
   - Поддерживает унарные + и -
   - Проверяет баланс скобок, пустые скобки, ожидаемые операнды.
3. Вычисление и обработка ошибок
   - Ошибки токенизации и парсинга преобразуются в ValueError с читаемыми сообщениями.
   - Деление на ноль преобразуется в ZeroDivisionError.
   - Операции // и % проверяются на целочисленные операнды — при нарушении выбрасывается ValueError.
   - Переполнение или слишком глубокая рекурсия также приводят к соответствующим ошибкам.
   - CLI ловит все исключения и выводит сообщение пользователю.

## Поддерживаемые операции
- Арифметические: `+`, `-`, `*`, `/`
- Целочисленные: `//` (деление), `%` (остаток)
- Степень: `**` (правоассоциативная)
- Унарные: `+`, `-`
- Скобки: `(`, `)`

## Принятые решения и допущения
- Парсер реализован как рекурсивный спуск — простая и прозрачная архитектура для данного набора операций.
- Токенизация отделена от парсинга с разделением проверок: токенизатор проверяет пропущенные операторы, парсер — структуру выражений.
- Целочисленное деление (//) и остаток от деления (%) разрешены только для целых чисел.

## Программа

### Установка

1. Создать и активировать виртуальное окружение:
