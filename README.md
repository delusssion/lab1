# Лабораторная работа 1 — Калькулятор (рекурсивный спуск)

Простой калькулятор выражений с разбором рекурсивным спуском, валидацией токенов и набором модульных тестов.

## Цель проекта
Реализовать парсер-вычислитель арифметических выражений (рекурсивный спуск) с корректной обработкой приоритетов операций, скобок, унарных операторов и проверкой распространённых ошибок ввода.

## Алгоритм работы калькулятора (кратко)
1. Tokenizer:
   - Очищает пробелы, разбивает входную строку на токены (числа, операторы, скобки).
   - Выполняет валидацию последовательности токенов (недопустимые символы, пустые скобки, ведущие нули, некорректные последовательности операторов и пр.).
2. Parser (рекурсивный спуск):
   - parse_expression → parse_addition → parse_multiplication → parse_power → parse_unary → parse_primary
   - Обрабатывает приоритеты: ** (правоассоциативно) → *, /, //, % → +, -
   - Поддерживает унарные + и -.
3. Вычисление и ошибки:
   - Деление на ноль преобразуется в ValueError('Деление на ноль').
   - Для операций // и % допускаются только целочисленные операнды.
   - Переполнение/слишком глубокая рекурсия — нормализуются в понятные ValueError.

## Принятые решения и допущения
- Парсер реализован как рекурсивный спуск — простая и прозрачная архитектура для данного набора операций.
- Токенизация отделена от парсинга для более чёткой валидации входа.
- Целочисленное деление (//) и модуль (%) разрешены только для целых чисел.
- Ошибки нормализуются в ValueError с читаемыми сообщениями, чтобы тесты и CLI получали единый формат ошибок.
- На вход принимаются числа в десятичной записи; точность float стандартная (ограничения плавающей точки — допустимое допущение).

## Тестирование
- Запуск всех тестов:
  - В виртуальном окружении из корня проекта:
    ```
    pytest -q
    ```
- Запуск pre-commit хуков локально:
  ```
  pre-commit run --all-files
  ```
- Статический анализ:
  ```
  mypy src tests
  ruff check .
  ```

## Запуск
1. Создать и активировать виртуальное окружение (macOS):
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Локальный запуск калькулятора (CLI):
   ```
   python -m src.main
   ```
   или
   ```
   python src/main.py
   ```
